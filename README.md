# 麻將 Checkpoint 連線伺服器

部署在 Cloudflare Workers（免費方案）的多人對戰伺服器。

- 每個房號是一個 Durable Object 房間，伺服器只負責轉送訊息。
- 洗牌、發牌、判斷由房主的瀏覽器負責；每個人的手牌在送出前已經加密，伺服器看不到。
- 沒有人說話時房間會休眠，不計運算時間。

## 設定

`wrangler.jsonc` 裡的 `ALLOWED_ORIGINS` 是允許連線的網站網址，多個用逗號分開。
網頁放在別的網址時，記得把它加進來。

## 確認是否正常

用瀏覽器打開 Worker 的網址，看到「麻將 Checkpoint 連線伺服器運作中」就代表部署成功。
